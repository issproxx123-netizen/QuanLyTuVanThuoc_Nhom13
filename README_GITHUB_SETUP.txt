BẮT ĐẦU GITHUB

1. Tạo một repository RỖNG trên GitHub, không chọn README/.gitignore/license.
2. Giải nén gói này.
3. Chạy 00_KHOI_TAO_VA_PUSH_GITHUB.bat.
4. Dán URL repository .git khi được hỏi.
5. Mời 5 thành viên vào Settings > Collaborators.
6. Mỗi thành viên clone repo, chạy 01_TAO_FEATURE_BRANCH.bat và commit thay đổi thật bằng tài khoản riêng.
7. Tạo Pull Request từ feature/* vào develop, review, kiểm thử và merge.
8. Mỗi Sprint tạo release branch/tag và GitHub Release v0.1, v0.2, v1.0.
9. Copy các file trong thư mục wiki/ vào tab Wiki của GitHub.

KHÔNG tạo commit giả hoặc sửa tên tác giả để giả lịch sử đóng góp.
