HƯỚNG DẪN VISUAL STUDIO + SQL SERVER ĐÃ LIÊN KẾT

1. THÔNG TIN KẾT NỐI
- Server: (localdb)\MSSQLLocalDB
- Database: QuanLyTuVanThuocDB
- Visual Studio dùng file appsettings.json để kết nối đúng database trên.
- File SQL nằm ngay trong project tại:
  QuanLyTuVanThuoc_Nhom13\Database\Tao_CSDL_QuanLyTuVanThuocDB.sql

2. CÁCH CHẠY NHANH KHÔNG XÓA DỮ LIỆU
- Mở QuanLyTuVanThuoc_Nhom13.sln.
- Build -> Rebuild Solution.
- Nhấn Ctrl + F5.
- Nếu database chưa có, Entity Framework tự tạo cấu trúc và dữ liệu mẫu.

3. CÁCH TẠO LẠI DATABASE TỪ SCRIPT SQL
- Đóng website nếu đang chạy.
- Bấm 01_TAO_LAI_CSDL_VA_CHAY_WEB.bat.
- Nhập YES để xác nhận.
- Script sẽ tạo lại database, sau đó website tự chạy.
- Cảnh báo: toàn bộ dữ liệu cũ bị xóa.

4. MỞ SQL TRONG VISUAL STUDIO
- Trong Solution Explorer mở project QuanLyTuVanThuoc_Nhom13.
- Mở thư mục Database.
- Nhấp đúp Tao_CSDL_QuanLyTuVanThuocDB.sql.

5. MỞ SQL TRONG SQL SERVER MANAGEMENT STUDIO
- Server name: (localdb)\MSSQLLocalDB
- Authentication: Windows Authentication
- File -> Open -> File.
- Chọn file SQL trong thư mục Database.
- Nhấn Execute hoặc F5.

6. KIỂM TRA KẾT NỐI
- Bấm 02_KIEM_TRA_KET_NOI_CSDL.bat.
- Kết quả đúng phải hiện database QuanLyTuVanThuocDB và số dòng mẫu.
