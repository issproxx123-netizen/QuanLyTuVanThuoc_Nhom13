HƯỚNG DẪN MỞ VÀ CHẠY – QUẢN LÝ TƯ VẤN THUỐC NHÓM 13

CÁCH NHANH NHẤT:
1. Mở QuanLyTuVanThuoc_Nhom13.sln bằng Visual Studio 2022.
2. Chờ Restore NuGet Packages.
3. Nhấn Ctrl + F5.
4. Web tự tạo database QuanLyTuVanThuocDB trên SQL Server LocalDB.
5. Đăng nhập admin / 123456.

HOẶC:
- Bấm đúp CHAY_NGAY_WEB.bat.
- Web chạy tại http://localhost:5088.

TÀI KHOẢN DEMO (mật khẩu chung 123456):
- admin: toàn quyền và quản lý tài khoản.
- bacsi: bệnh nhân và phiếu tư vấn.
- kho: thuốc, loại thuốc và nhập kho.
- quanly: xem dashboard, cảnh báo và báo cáo.

NẾU LOCALDB CHƯA CÓ:
- Mở Visual Studio Installer.
- Chọn Modify.
- Cài workload ASP.NET and web development và Data storage and processing.

FILE SQL THỦ CÔNG:
- Database/Tao_CSDL_QuanLyTuVanThuocDB.sql
- Có thể chạy trong SQL Server Management Studio nếu không muốn web tự tạo dữ liệu.
