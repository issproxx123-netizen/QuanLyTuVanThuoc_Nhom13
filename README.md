# Hệ thống Quản lý Tư vấn Thuốc - Nhóm 13

## Mô tả đề tài

Website hỗ trợ phòng khám quản lý quy trình tư vấn thuốc, bao gồm tiếp nhận bệnh nhân, quản lý kho thuốc, lập phiếu tư vấn, kiểm tra cảnh báo dị ứng, theo dõi tồn kho và báo cáo thống kê.

## Công nghệ sử dụng

- ASP.NET Core MVC .NET 8
- Entity Framework Core
- SQL Server / LocalDB
- HTML, CSS, JavaScript
- Figma UI Design

## Chức năng chính

1. Dashboard tổng quan
2. Quản lý bệnh nhân
3. Quản lý kho dược phẩm
4. Lập phiếu tư vấn thuốc
5. Tự động trừ tồn kho sau khi lập phiếu
6. Cảnh báo dị ứng thuốc
7. Cảnh báo thuốc tồn kho thấp
8. Cảnh báo thuốc sắp hết hạn
9. Báo cáo thống kê
10. In phiếu tư vấn và báo cáo

## Cách chạy

1. Chạy file SQL trong thư mục `Database`.
2. Mở file `QuanLyTuVanThuoc_Nhom13.sln` bằng Visual Studio.
3. Bấm `Ctrl + F5`.
